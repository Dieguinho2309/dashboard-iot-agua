# Frontend · AquaMagdalena

Este directorio contiene únicamente el frontend del dashboard.

**La documentación del proyecto está en [`../README.md`](../README.md)** — tecnologías, puesta en marcha, estructura completa y notas de implementación.

```bash
npm install
npm run dev
```

Sin variables de entorno el frontend corre en **modo simulado**. Para usar la API real, crea `frontend/.env.local` con:

```bash
VITE_API_URL=http://localhost:3001
```
